## 1. フレームレート（目標 72fps）

アプリが 10 秒ごとに `[ILAB] perf ...` を `ilab_log.txt` に書く（`PerfMonitor`）。

| 場面 | やること | 時間 |
|---|---|---|
| 研究室で待機 | パネルを見たまま動かない | 30秒 |
| 研究室を見回す | 頭を左右・上下に動かす | 30秒 |
| 雨の実験（DREAM） | サンプル雨具で実験を開始し、終わるまで見る | 1回 |
| 雨の実験（REALITY） | REALITY に切り替えて同じく実験 | 1回 |
| 係数表 | 実験設定 → REALITY → 前提係数と出典を3ページめくる | 30秒 |

終わったらログを取り出す：

```bash
MSYS_NO_PATHCONV=1 "$ADB" pull /sdcard/Android/data/jp.impossiblelab.vr/files/ilab_log.txt Logs/quest_ilab_log.txt
grep "perf" Logs/quest_ilab_log.txt
```

読み方：`fps_avg`（平均）、`p95`（遅い方から5%のフレーム時間）、`slow`（1フレーム以上落ちた割合）、`ok=yes`（平均が目標の95%以上かつ落ちたフレームが1%以下）、`state`（その10秒間の画面。`+rain` は雨の実験中）。

## 3. AT-06 保存 → 再起動 → 復元

1. サンプル雨具を作り、「範囲を広げて」などで改良して承認、保存する。保存した版（Rev.）とパラメータの値をメモする。

## 8. 追加機能の確認（2026-11-09 実装分）

- クイック発明「空を飛べる靴」「自動でついてくる運搬ロボット」→ 承認 →「● 起動（試用）」：ロボットが床に降りてついてくる／靴が浮く。
- 運搬：実験 → 衝突あり → 「障害物をよけて」→ 再実験で衝突が減る。障害物とロボットがパネル越しに見えるか。
- 移動：風向を「前へ（0°）」・風速4にして実験 →「風で揺れないようにして」→ 安定度が上がる。REALITY で電池切れの表示。飛ぶ様子を見て酔わないか。
- 効果音：ボタン・生成完了・実験開始・結果で鳴るか。大きすぎないか（手元メニューでオフにできる）。
- 手元メニュー：左コントローラーを顔の前に持ってくると出るか、勝手に出たり消えたりしないか、右手のレイで押せるか。
- 外観：編集画面の左パネル「外観 ◀ ▶」で色が変わるか。
- 音声入力：入力欄 → キーボードのマイクボタンで日本語が入るか（Quest の機能）。
- 運搬・移動の perf ログ（`state=...+ObstacleCourse` / `+FlightDeck`）。
