# REALITY MODE 簡易物理モデル（hover_canopy_v1）

更新：2026-11-09（係数の出典調査を反映） ／ 対象：ハンズフリー雨具（頭上追従キャノピー）
係数データ：`Assets/_ImpossibleLab/Data/Reality/Resources/ImpossibleLabData/reality_model.json`
実装：`Assets/_ImpossibleLab/Scripts/Core/RealityModel.cs`（`ModeRules.Evaluate` から呼ばれる）

> このモデルは発表・教育用の **参考値** です。現実の製品としての性能・安全性は保証しません（仕様 1.2, 10章）。
> 雨の当たり判定（被濡れスコア・防護率）と DREAM MODE には影響しません。

## 1. 目的

従来の REALITY は「消費電力 = 25 + 90×面積 + …」のように根拠のない係数を使っていた（DECISIONS Q-02）。
これを **教科書的な物理式** と **出典・確度つきの仮定値** に置き換え、仮定の不確かさを **幅（悲観〜楽観）** で表示する。

## 2. 計算式

| 量 | 式 | 備考 |
|---|---|---|
| 総質量 m | 本体 + πr²×キャノピー面密度 + 2πr×L×側面カバー面密度 + 電池 | r：半径、L：側面カバー長 |
| 重さ W | m × g（g = 9.80665 m/s²） | 標準重力加速度 |
| 横から見た面積 A_side | 2r ×（キャノピー側面高さ比×r + L） | 浅いドーム＋側面カバーを長方形で近似 |
| 風荷重 F | ½ ρ C_d A_side v² | 抗力の基本式 |
| 必要推力 T | √(W² + F²) | 風に逆らって傾いた状態の釣り合い |
| 傾き θ | atan(F / W) | θ > 最大傾き なら「位置を保てない」 |
| 理想ホバー電力 P_ideal | T^1.5 / √(2 ρ A_rotor) | 運動量理論（アクチュエータ円板） |
| 消費電力 P | P_ideal ÷ (FM × 駆動効率) + 制御電力 | FM：性能指数 |
| 電池容量 E | 電池質量 × エネルギー密度 × 使用可能割合 | |
| 稼働時間 | E ÷ P | |
| 位置ずれ | F ÷ (K₀ ×（1 + k × 安定化の強さ）) | **調整用の仮定**（制御器に依存し物理的根拠なし） |

### 単純化と、その影響

- 風の中でホバリングすることは前進飛行に近く、実際は誘導電力が **下がる**。この効果を無視しているため、電力は **多めに**（保守側に）見積もっている。
- ロータとキャノピーの干渉、雨水の重さ、突風、地面効果、プロペラの騒音・安全性は扱っていない。
- 位置ずれは制御性能で大きく変わるため、物理式ではなく調整用の仮定値で表す。

## 3. 幅（悲観〜楽観）の出し方

各係数に `min` / `max` と `better`（大きいほど稼働時間が延びるか）を持たせている。

- **楽観**：すべての係数を、稼働時間が延びる側の端に置く
- **悲観**：すべての係数を、稼働時間が縮む側の端に置く
- **中央値**：`value`

すべての係数が同時に端の値を取るとは限らないため、幅は「最悪〜最良の組み合わせ」で、実際より広めに出る。
空気密度は電力を下げる側と風荷重を上げる側に同時に効くが、稼働時間の向き（`better: high`）にそろえている。

## 4. 確度の区分

| status | 画面表示 | 意味 |
|---|---|---|
| standard | 標準値 | 規格などで定まっている値 |
| literature | 文献値・要確認 | 実測論文・メーカー公式仕様・販売仕様などの値。原典の該当ページや形状への当てはめは要確認 |
| design | 設計上の仮定 | この発明の設計として決めた値（調べて確かめる対象ではない） |
| estimate | 推定・要調査 | 仮置きした値。根拠となる資料を探す必要がある |
| tuning | 調整用仮定 | 見た目や挙動を整えるための値 |

## 5. 計算例（中央値、カッコ内は悲観〜楽観）

2026-11-09 の係数で、Python で同じ式を再計算した値（`RealityModel.Estimate` と同じ式）。

| 設計・条件 | 総重量 | 風荷重 | 消費電力 | 稼働時間 | 位置ずれ |
|---|---|---|---|---|---|
| 半径0.6 m・カバーなし・安定0.3・風3 m/s（サンプル初期） | 1.76 kg | 0.9 N | 238 W（146〜498） | 13 分（4.4〜27） | 0.06 m |
| 同・風8 m/s | 1.76 kg | 6.2 N | 260 W（153〜557） | 12 分（4.0〜26） | 0.41 m |
| 半径0.8 m・カバー0.25 m・風4 m/s（自動検証の Rev.3） | 2.31 kg | 7.1 N | 377 W（210〜810） | 8.5 分（2.7〜19） | 0.47 m |
| 同・風8 m/s | 2.31 kg | 28.3 N | 703 W | 4.5 分 | 傾き51°で **位置を保てない** |

旧係数（2026-11-04）では、サンプル初期 303 W・10 分、Rev.3 470 W・6.4 分だった。本体質量（1.2→0.9 kg）と側面カバーの面密度（0.2→0.12 kg/m²）を市販品の仕様に合わせて下げたことが主な差。

### 市販ドローンでの当てはめ確認（2026-11-09）

DJI Phantom 4 Pro V2.0 の公式仕様（総重量 1375 g、電池 468 g・89.2 Wh、9.45インチのロータ4基、公称飛行時間 約30分）を、キャノピーなし・無風でこのモデルに入れた。

| 条件 | 消費電力 | 飛行時間 |
|---|---|---|
| 中央値・使用可能割合0.8 | 177 W | 24 分 |
| 中央値・電池を100%使用 | 177 W | 30 分 |
| 悲観〜楽観（使用割合0.8） | 247〜138 W | 15〜33 分 |

公称の約30分（メーカーの測定条件は前進飛行で、ホバーより電力が少ない）と大きくは外れない。ただし1機種の比較であり、モデルの正しさを示すものではない。

読み取れること（発表で使える）：

- 側面カバーは横からの雨を防ぐが、風を受ける「帆」になり、強風で位置を保てなくなる（防護と安定のトレードオフ）。
- 仮定の幅が 4〜27 分と大きく、実機の重量・推力の測定が必要だとわかる。

## 7. テスト

`Assets/_ImpossibleLab/Tests/EditMode/CoreTests.cs`

- `RealityModel_LoadsWithSourcesAndStatus`：必須係数がそろっていて、全係数に出典と確度があること
- `RealityModel_HoverPower_MatchesMomentumTheory`：無風・キャノピーなしで、手計算の運動量理論の値と一致すること
- `RealityModel_RangeBracketsNominal`：悲観 ≤ 中央値 ≤ 楽観

- `Reality_StrongWindWithLargeSkirt_CannotHoldPosition`：強風＋大きいカバーで「位置を保てない」となること
- `RealityModel_Parse_RejectsInvalidData`：必須係数の欠落、範囲外の値、効率が1を超える値、壊れたJSONを拒否すること
