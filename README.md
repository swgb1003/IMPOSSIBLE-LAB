# IMPOSSIBLE LAB — Claude Code開発パッケージ

1. ZIPを展開し、**既存のUnityプロジェクトのルート**に `CLAUDE.md`、`docs/`、`DesignReferences/` をコピーしてください（既存の同名ファイルがある場合は内容を統合）。
2. プロジェクトルートでClaude Codeを起動してください。
3. 「CLAUDE.mdとdocs/IMPOSSIBLE_LAB_開発仕様書_v2.0.mdを読み、環境調査から開始。既存ファイルを壊さず、最初の縦切り実装に着手してください」と指示します。
4. Claude CodeがUnity EditorやQuest実機を操作できない環境では、生成したコードをUnityで開いてビルド・動作確認してください。

**内容**：詳細仕様書v2、Claude Code作業指示、実装ログ、判断ログ、採用済みデザイン画像3点。APIキーやUnityプロジェクト本体は含みません。
